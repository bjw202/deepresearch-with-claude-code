Al2O3 피막의 이중 구조가 3가지 치명적 결함을 숨긴다

다공층 (Porous Layer) — 두께 10~25 µm
바깥쪽 · 색소 흡착 · 기능층
기공 직경 10~100 nm의 세포-기공 구조
장벽층 (Barrier Layer) — 두께 10~100 nm
안쪽 · 치밀한 비결정질 Al2O3
부식 보호의 핵심 · 두께 ∝ 양극산화 전압
알루미늄 모재 (AA6063 / 6061 / 7075)
💡 메타포: 다층 우산 — 바깥층이 큰 빗방울을 막고, 안층이 모재까지 새지 않게 한다
숨겨진 3가지 결함
① 기공 미봉공
봉공이 덜 되면 기공이 열린 채로 남아 수분·염화물이 모재까지 침투하는 통로가 된다
② 미세 균열 (crack)
열사이클·기계 충격으로 미세 균열 발생 → 응력 집중 → 박리 진행. 초기에는 육안 불가
③ 갈바닉 부식 개시
AA7075의 Cu 함유 인터메탈릭 입자가 부식 시드로 작용 → 국소 R_ct 급락

EIS는 교류 신호로 피막을 비파괴 진단하는 전기 청진기다

📐 임피던스(Z) = 주파수에 따라 달라지는 AC 저항
DC 저항은 숫자 하나. 임피던스는 두 정보를 동시에 담는다:
|Z| (크기) = 신호가 얼마나 막히는가 (Ω·cm²)
φ (위상각) = 전압과 전류의 시간차 (°)
💡 신분증 비유: |Z|는 "얼마나 까다로운가", φ는 "얼마나 늦게 반응하는가"
🔬 왜 작은 AC 신호인가 (±10~20 mV)
① 비파괴: 큰 전압을 걸면 피막이 변형됨. 26 mV 미만에서는 피막이 평형 유지
② 층 분리: 빠른 신호 → 다공층만 반응, 느린 신호 → 장벽층까지 반응
📡 주파수 0.01 Hz ~ 100 kHz 스위프
💡 셔터 속도 비유: 고주파 = 빠른 셔터(빠른 과정만), 저주파 = 느린 셔터(느린 과정까지)
주파수 영역별로 보이는 것
> 100 kHz
용액 저항 R_s만 보임 (전해질 고유 저항)
1 kHz ~ 100 kHz
다공층 (porous layer) 응답
1 Hz ~ 1 kHz
장벽층 (barrier layer) 응답
< 0.1 Hz
확산 과정, 피막 열화 신호 포착
장벽층 깊은 정보를 보려면 반드시 0.01 Hz까지 측정해야 한다

Nyquist vs Bode: 같은 데이터를 두 가지 시각으로 읽는다

Nyquist Plot (복소평면 도형)
-Z''
 ↑
 │   ╭──────────╮
 │  ╭──╮         │
 │  │  │(다공층)  │
 │  ╰──╯  (장벽층) │
 │                │
 └─────────────────→ Z'
강점
• 반원 개수로 시정수(층) 수 즉시 파악
• 반원 지름 = 그 층의 저항
• 등가회로 구조를 직관적으로 선택 가능
약점
• 각 점의 주파수 정보가 숨겨짐
Bode Plot (주파수 응답 도형)
log|Z|
 ↑ ╲────────────
 │     ╲
 │       ╲───────────
 └──────────────→ log(f)

φ(°)
 ↑ ──╮     ╭──
 │    ╰──────╯
 └──────────────→ log(f)
강점
• 각 점의 주파수를 직접 읽을 수 있음
• 넓은 주파수 범위 거동 한눈에 파악
• 저주파 |Z| = 부식 보호력 직접 지표
약점
• 등가회로 구조를 직관적으로 읽기 어려움
실무에서는 항상 두 플롯을 같이 본다 — Nyquist로 구조 파악, Bode로 주파수 위치 확인

양극산화 피막은 이중 방어선(다공층+장벽층)으로 구성된다

외성: 다공층 (Porous Layer)
두께 10~25 µm | 기공 직경 10~100 nm
색소·윤활을 담당하지만 기공이 열리면 부식 통로
R_pore: 기공 내 이온이 통과하기 어려운 정도
내성: 장벽층 (Barrier Layer)
두께 10~100 nm (약 1~1.5 nm/V) | 치밀한 Al2O3
부식 보호의 핵심 — 이온 침투를 근본적으로 차단
R_barrier: 황산 표준 양극산화+봉공 시 10⁵~10⁸ Ω·cm²
💡 CPE (Constant Phase Element): 실제 피막은 두께·거칠기가 불균일해 이상적 커패시터(C)로 표현 불가. CPE 지수 n=1이면 완벽한 커패시터, n이 낮을수록 결함 의심. 장벽층 n: 0.85~0.98 / 다공층 n: 0.7~0.9
Hitzig 이중층 등가회로

EIS vs ISO 2931 vs Salt Spray: 각 도구의 역할이 다르다

평가법 비파괴 측정시간 층 분리 비용 산업 표준 주요 용도
EIS ✓ 30분~2시간 ✓ (다공/장벽) 높음 ($10K~) — R&D / 공정 최적화
ISO 2931 어드미턴스 ✓ < 5분 ✗ 낮음 ($500~) ISO 2931:2017 양산 QC

⚠ AASS 경고

✓ 최고 조합
EIS + SEM (가장 보편적): EIS로 이상 감지 → SEM 단면으로 손상 위치 시각 확인

EIS 측정 시 반드시 피해야 할 4가지 함정

⚗️
함정 1
참조 전극 오염
참조 전극의 frit(액락)이 오염되면 측정 임피던스에 아티팩트 추가. 참조 전극 임피던스가 정상의 2~3배 이상이면 신뢰도 급락
→ 사용 전 임피던스 확인 필수
🧹
함정 2
시편 표면 오염
염화물·기름·지문이 국소 저항을 변화시켜 Nyquist 반원이 비대칭으로 일그러짐. 작은 지문 하나가 결과를 오염시킨다
→ 아세톤 → IPA 순차 세정 필수
⏱️
함정 3
OCP 미안정
침지 후 바로 측정하면 안 된다. 전극 전위가 안정될 때까지 대기 필요. OCP 변동이 크면 측정 중 시스템이 변화
→ 30분 이상 대기, 변동 <2 mV/min 확인
🎯
함정 4
면적 정규화 누락
1 cm² vs 100 cm² 시편의 임피던스를 면적 보정 없이 비교하면 오더 단위 오류. 반드시 Ω·cm²로 정규화 보고
→ 항상 측정 면적 마스킹 & Ω·cm² 단위 사용
💡 KK 검증 필수: 등가회로 피팅 전에 반드시 Kramers-Kronig 변환 잔차(residual) < 1~2% 확인. 데이터가 부실하면 어떤 해석도 무의미하다

EIS는 R&D의 무기
피막의 보이지 않는 방어선을 수치로 증명하라

EIS는 다공층과 장벽층을 한 번의 비파괴 측정으로 분리 수치화할 수 있는 유일한 도구다
양산 QC는 ISO 2931 어드미턴스, 인증은 Salt Spray가 표준 — EIS는 신규 공정·봉공 최적화·열화 메커니즘 분석에 활용
가장 큰 함정: 등가회로 비유일성 — 항상 물리적 근거를 명시하고, KK 검증 후 피팅하라
상황별 도구 선택
신규 전해질 평가 → EIS
봉공 방법 비교 → EIS + 시계열
양산 라인 QC → ISO 2931
출하 인증 → Salt Spray (NSS 우선)
핵심 수치 요약
|Z|@0.01Hz > 10⁶ Ω·cm² → 우수
위상각 -80° ~ -90° → 이상적 절연
R_barrier 10⁵~10⁸ Ω·cm² (황산+봉공)
f_b < 1 Hz → 완전 봉공
